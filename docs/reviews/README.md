# Published pack reviews

Practitioner reviews of AI-MRG packs are published here, one file per review, named
`<pack>/<version>/<date>-<reviewer-or-anonymous>.md`. They are generated with
`aimrg pack review-summary` and approved by the reviewer before publication.

See [Reviewing a governance pack](../review/guide.md) for the process.
